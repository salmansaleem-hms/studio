# **App Name**: Salman Saleem Portfolio

## Core Features:

- Profile Display: Display a professional profile with sections for About Me, Education, Work Experience, Skills, Projects, and Certifications.
- Navigation: Provide a clear, navigable structure with a header containing navigation links to each section.
- Skills Showcase: Highlight skills with categorized lists (Web Development, Digital Marketing Tools, Office & Admin Tools).
- Contact Information: Include a contact section with clickable links for email and LinkedIn, and a simple contact form.
- Resume Access: Enable users to easily download Salman's resume as a PDF from the hero section or view it in another section of the site.
- AI-Driven Personalization: AI powered tool for personalizing page content, if the user seems to match job descriptions for administrative or technical roles. 

## Style Guidelines:

- Primary color: Subtle teal (#388E8E) to reflect professionalism and technical skills.
- Background color: Light gray (#F0F0F0) to provide a clean, modern backdrop.
- Accent color: Darker teal (#266060) to highlight important elements and calls to action.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text.
- Use modern, minimalist icons to represent different skills and sections. Icons should complement the teal color scheme.
- Maintain a clean, well-spaced layout with ample whitespace. The design should be responsive and optimized for various devices.
- Implement subtle hover effects on links and buttons. Consider smooth scrolling to enhance the user experience.
